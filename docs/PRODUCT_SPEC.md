# Product Spec

**User:** an early-career engineer tracking startups and applications.

**Must do:** import CSV · dashboard (total, researched, applied, replies, interviews) · filter by funding status, stage, location, industry, engineering roles · research careers page / public email / roles with source URLs · statuses Not Applied, To Apply, Applied, Replied, Interview, Rejected, Offer · notes, dates, contact details · search and edit · CSV export.

**Rules:** never invent funding, emails, jobs or URLs; distinguish verified from unknown; no auto-sent email; polite fetching only.

See `README.md` for current implementation status.
